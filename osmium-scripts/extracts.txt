# The Geofabrik extracts the map is built from: one per line, the extract's
# path on download.geofabrik.de without the -latest.osm.pbf.
#
# Every extract is downloaded, filtered down to railways and deleted before the
# next one comes in; prepare.sh then merges the filtered files into one map.
# That is why Europe is listed country by country rather than downloaded whole:
# the continent is 32GB+ and the server has less disk than that, while the
# largest country is under 5GB. Neighbouring extracts overlap at the border, and
# the merge keeps one copy of every object - the newest, if the two extracts
# are a day apart.
#
# Nothing here says which region an extract belongs to, because nothing needs
# to: a region is a bounding box (src/lib/shared/regions.ts), applied when the
# data is read, and the regions are far enough apart that merging them changes
# nothing.
#
# Europe's list is every region Geofabrik's Europe page lists
# (download.geofabrik.de/europe.html), so the data is the same as the whole
# continent's extract: track everywhere on the admin map, whether or not the
# country is on the user map (SUPPORTED_COUNTRIES in
# src/lib/shared/constants.ts) or has routes yet. Three adjustments:
#
# - Iceland and the Azores are left out: both lie west of the Europe region's
#   12W edge (src/lib/shared/regions.ts), so nothing of them would ever be
#   drawn.
# - "Russian Federation" links to Geofabrik's Russia, which covers all of it.
#   The continent's extract reaches only as far as 46.8E, so it is taken as the
#   federal districts inside that line. The Volga and Northwestern districts
#   run on further east, and that extra is harmless: the Europe region is cut
#   at 40E (src/lib/shared/regions.ts), so it is never drawn. Crimea's
#   district is left out, Geofabrik's Ukraine including Crimea already.
# - The page's "special sub regions" (Alps, DACH, Britain and Ireland, Great
#   Britain) are left out: each is only a combination of countries listed here.
#
# Adding an extract: add its line (the path of its -latest.osm.pbf on
# Geofabrik, without the suffix), commit, push, deploy.
