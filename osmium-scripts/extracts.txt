# The Geofabrik extracts the map is built from: one per line, the extract's
# path on download.geofabrik.de without the -latest.osm.pbf.
#
# Every extract is downloaded, filtered down to railways and deleted, the next
# one downloading while the previous is filtered; prepare.sh then merges the
# filtered files into one map. That is why Europe is listed country by country
# rather than downloaded whole: the continent is 32GB+ and the server has less
# disk than that, while the largest country is under 5GB. Neighbouring extracts overlap at the border, and
# the merge keeps one copy of every object - the newest, if the two extracts
# are a day apart.
#
# Nothing here says which region an extract belongs to, because nothing needs
# to: a region is a bounding box (src/lib/shared/regions.ts), applied when the
# data is read, and the regions are far enough apart that merging them changes
# nothing.
#
# Europe's list is the regions on Geofabrik's Europe page
# (download.geofabrik.de/europe.html), so there is track on the admin map
# whether or not the country is on the user map (SUPPORTED_COUNTRIES in
# src/lib/shared/constants.ts) or has routes yet. Left out:
#
# - Russia (Kaliningrad included), Ukraine, Belarus and Turkey: big networks we
#   don't map, which cost download, filter and import time on every deploy for
#   track nothing uses. No route crosses into them, and the neighbours' extracts
#   overlap the border, so the track up to it stays. Checked 2026-11-20 against
#   every route and scenic line: none ran along a part only these extracts
#   carried (the nearest was 460m off, at Ormenio), and no station within 250m
#   of a route was lost. Belarus checked the same way 2026-11-21 (nearest 3.5km,
#   Chełm - Włodawa). Re-check before adding a route near those borders
#   that runs right up to one.
# - Cyprus, Malta and the Faroe Islands: no railway at all (Cyprus has a few
#   preserved display tracks, the Faroes a short industrial line), so nothing
#   to draw.
# - Iceland and the Azores: both lie west of the Europe region's 12W edge
#   (src/lib/shared/regions.ts), so nothing of them would ever be drawn.
# - The page's "special sub regions" (Alps, DACH, Britain and Ireland, Great
#   Britain): each is only a combination of countries listed here.
#
# A route running into a region missing from this list goes invalid on import.
#
# Adding an extract: add its line (the path of its -latest.osm.pbf on
# Geofabrik, without the suffix), commit, push, deploy. Russia is not one
# extract on the Europe page but Geofabrik's Russia, split into federal
# districts (russia/<name>-fed-district; Kaliningrad is russia/kaliningrad).
